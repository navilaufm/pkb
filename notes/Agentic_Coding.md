# Agentic Coding

**Summary**: Notes on AI agents and tools that write, build, and ship software from natural-language descriptions.
**Last updated**: 2026-08-27

---

- [Create Reusable GIS Workflows with GeoLibre Model Builder and AI Assistant](https://www.linkedin.com/posts/giswqs_gis-geospatial-opensource-share-7498007103715074049-CAet/): LinkedIn post by Qiusheng Wu demoing GeoLibre, a free open-source, browser-based (WebAssembly) GIS tool with 1,000+ geoprocessing tools, whose AI Assistant builds a complete graphical [[Remote_Sensing|geoprocessing]] workflow — e.g. DEM stream-network extraction — from a natural-language prompt. keywords: GeoLibre, GIS workflows, WebAssembly, AI assistant, geoprocessing, open source
- See [[Climate_Change]] for a note on Meteo.Tech, a weather-risk platform built on proactive AI agents.
- See [[Python]] for a note on a full Python course with AI-assisted coding exercises.
- [Dactyl](https://dactyl.dev/): Describe an app, watch it build live in your browser, then install it on your iPhone, iPad, or Android phone. Ship to TestFlight and the App Store. No Mac, no Xcode. An AI agent writes real native SwiftUI code (compiled to Android too) from a plain-language description, with an in-browser live preview, built-in backend (accounts, data, realtime sync), and guided App Store submission. keywords: AI app builder, no-code, SwiftUI, native apps, agentic coding, App Store
