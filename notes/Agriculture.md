- [agribound](https://github.com/montimaj/agribound): Python package for delineating field boundaries. An AI-powered [[Python]] toolkit that detects and maps agricultural field boundaries from satellite imagery, combining object detection, semantic segmentation, foundation models, and embedding-based clustering ([[Deep_Learning]]) with data from Sentinel-2, Landsat, and NAIP, while filtering out non-agricultural features like roads and forests.
